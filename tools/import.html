Schedule import

Paste a new or corrected schedule for one festival day and weekend. This page checks it, shows exactly what changes compared with the committed data, and builds the replacement data/<schedule>.js. It never writes files itself: save the output, run node tools/check-schedules.js, look at git diff, commit.

    One stage name per block (optionally | stream URL), then one act per line with its time first or last. Blank lines between stages. JSON also works: a stages array, {stages:[…]}, or a one-weekend {weekends:{…}}. A stage without a URL keeps its current one.

    Prompt to use when converting a festival web page in a chat 
    Convert the schedule below into exactly this plain-text format and output nothing else:

<Stage name> | <livestream URL if given, otherwise omit the " | " part>
<h:mm AM/PM>  <Artist name exactly as written>
<h:mm AM/PM>  <Artist name>

(blank line between stages)

Rules: one act per line; start time only (drop end times); keep the times in the
timezone the source uses and tell me which timezone that is; keep every stage and act;
don't fix spelling or add commentary.
